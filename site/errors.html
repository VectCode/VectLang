Error catalog

Every fault prints [Vect Runtime Error]: … at line N to stderr and exits 1. Compile-time faults fire before anything runs; runtime faults halt mid-program. Faults inside .vth files add the filename.

Reading an error

[Vect Runtime Error]: Index 5 out of bounds (len 3) at line 14 (game.vt)
[Vect Execution Terminated]

Three parts: what (with the offending values filled in), where (line, plus file when inside a header), and the termination banner. Exit code is always 1 for these (2 means you gave vectc no file at all). Program output before the fault stays on stdout; the error itself is on stderr, so vect p.vt > out.txt keeps them separated.
