1 · File header

Every .vt file starts with the init block, then function definitions, then a call:

vt.init
mvga.vth
(main)
branch
vectfn main
    ...
main()

vt.init prepares the runtime, (main) selects the entry point, branch transfers control. Blocks are 4-space indented, one statement per line, no semicolons.

2 · Variables

Compact assignment: trailing digits are the value.

x10          cmt x = 10
count100     cmt count = 100
timer0       cmt timer = 0
msg"hi"      cmt string assignment

3 · Math — target notation

All arithmetic uses (target.expression):

(c.a+b)                 cmt c = a + b
(total.c*2)             cmt total = c * 2
(root.sqrt.val)         cmt square root
(shlRes.bit shl a, 2)   cmt 10 << 2 = 40
(shrRes.bit shr b, 1)   cmt 20 >> 1 = 10
(inv.bit not v)         cmt bitwise NOT
(r.a AND b) (r.a OR b) (r.a XOR b)

Operators: + - * / %, comparisons == != < <= > >=. Division by zero halts the program immediately.

4 · Branching & loops

if x > 10
    echo "big"
els
    echo "small"
lo10                     cmt run 10 times
    (counter.counter+1)
lo10w running == 1       cmt up to 10x while true
    (val.val+1)

5 · Functions

vectfn add.a, b
    (sum.a+b)
    rtn sum
vectfn main
    (result.add 25, 75)
    echo result
main()

6 · Arrays

scores(3)                 cmt allocate 3 slots, zeroed
set scores, 0, 10        cmt write index 0
(firstScore.get scores, 0)
echo firstScore

Out-of-bounds access halts the program with a line number.

8 · File I/O

fopen fh, "notes.txt", "w"   cmt modes: "r" read, "w" write
fwrite fh, "hello vect"
fclose fh
fopen fr, "notes.txt", "r"
(s.fread fr, 64)              cmt up to 64 bytes, "" at EOF
fclose fr

Paths resolve relative to where you run vectc.

9 · Header libraries (.vth)

List a .vth file in the header to load reusable vectfn definitions. Headers may only contain comments, header lines and vectfn blocks. Includes resolve relative to the file that names them, nest, and never load twice.

10 · Comments

cmt starts a comment to end of line, full-line or trailing:

cmt a full line note
x10 cmt trailing note

11 · Hardware stubs

Hosted vectc maps hardware primitives to safe stubs: vga0x320200 prints an init banner, pout(port, val) is accepted and ignored. A real framebuffer backend is planned.

12 · Errors

Vect uses immediate failure: any runtime fault (division by zero, bad index, bad handle, unknown variable) prints to stderr and exits non-zero:

[Vect Runtime Error]: Division by zero at line 14
[Vect Execution Terminated]

13 · vectc CLI

vectc program.vt            cmt compile + run
vectc --dump program.vt     cmt print bytecode, don't run
