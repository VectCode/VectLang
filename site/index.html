Code dense. Run fast.

Vect is a minimalist low-level language: whole programs in a handful of lines, direct memory and hardware primitives, zero boilerplate.

Designed and built solo by paraxapp — a real human with a public roadmap. No team, no funding, no vapor.

Ultra-compact

x10 declares x = 10. (c.a+b) is c = a + b. No semicolons, no braces.

Low-level

Arrays, pointers, port I/O, VGA pixel primitives and fixed-point math built in.

Real toolchain

vectc compiles .vt to bytecode and runs it on a stack VM. --dump shows the bytecode.

Scriptable I/O

echo, echow, in() plus file primitives fopen/fread/fwrite/fclose.

How it works

1 · Write .vt

Compact source: header, functions, one statement per line. Any editor (ours for VS Code helps).

2 · vectc compiles

Lexer → parser → 50-op bytecode, one chunk per function. --dump shows every instruction.

3 · VM runs

Stack machine: slots for variables, frames for calls, arena for data. Errors halt with file + line.
