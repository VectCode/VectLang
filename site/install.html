Installation

Requirements

Windows 10/11 x64. No dependencies, no admin rights, no installer — one vectc.exe, ~1 MB.

Option A · Scoop (recommended)

> scoop bucket add vect https://github.com/MerixCipher/scoop-bucket
> scoop install vect/vectc

This puts both vect and vectc on your PATH. Update anytime with scoop update vectc, remove with scoop uninstall vectc. Full guide: Scoop page.

Option B · Zip

  1. Download from the download page.
  2. Unzip anywhere, e.g. C:\tools\vect.
  3. Optional: add that folder to PATH (Settings → System → About → Advanced → Environment Variables).

Verify

> vect --version
vectc 0.2.4
> Get-FileHash vectc-v0.2.4-windows-x64.zip -Algorithm SHA256

Compare the hash with the one in the Scoop manifest, and check the VirusTotal report for the release.

Troubleshooting

SymptomFix
