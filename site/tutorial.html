Tutorial: guess the word

We build Hangman in ~50 lines, one idea at a time. Run each step with vect guess.vt.

Step 1 · State

Secret word, revealed flags, lives, progress. Arrays hold per-letter state:

msg"vect"
(n.len msg)
rev(4)
lives6
shown0
done0

Step 2 · Draw the board

Rebuild the display string every turn — revealed letters or underscores:

disp""
i0
lo4
    (flag.get rev, i)
    (code.char msg, i)
    if flag == 1
        (ch.chr code)
        (disp.cat disp, ch)
    els
        (disp.cat disp, "_")
    (i.i+1)
echo disp

Step 3 · Guess

Read a letter, normalize it (empty input becomes "0" instead of crashing), scan for hits:

in(guess)
(clean.cat guess, "")
(gcode.char clean, 0)
found0
j0
lo4
    (code2.char msg, j)
    if code2 == gcode
        (old.get rev, j)
        if old == 0
            set rev, j, 1
            (shown.shown+1)
        found1
    (j.j+1)
if found == 0
    (lives.lives-1)

Step 4 · End conditions

Wrap steps 2–3 in lo100w done == 0 and stop on win or loss:

if shown == n
    echo "win"
    done1
if lives == 0
    echo "lose, word was:"
    echo msg
    done1

Exercises

  • Change the word (adjust the two lo4s to match its length).
  • Track wrong letters in a second array and display them.
  • Persist best score with kvset/kvsave.

Step 5 · Debugging it when it breaks

You will meet these three faults while building — here's what each means:

ErrorUsual cause
Undefined variable 'x'Reading a name you never assigned. Check for (x…) (read) vs x… (write) confusion.
Index out of boundsLoop counter ran past the word: your lo4 doesn't match the word length.
char needs a stringEmpty in() gives int 0. Normalize with (clean.cat guess, "") first.

Where this took you

You now own: compact assignment, target math, both loop forms, if/els, arrays, string ops (len/char/chr/cat), input normalization, and state flags. That's ~80% of everyday Vect — the rest is files, stores, and headers in chapter 3 of the reference.
