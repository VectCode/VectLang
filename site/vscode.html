VS Code extension

Install (manual, for now)

  1. Open the vscode-vect folder from the repo in VS Code.
  2. Press F5 — an Extension Development Host opens with Vect enabled.
  3. Open any .vt file there. Marketplace publishing is planned.

Features

  • Syntax highlighting for .vt/.vth: keywords, target expressions, compact assigns, loops, strings, comments.
  • cmt comment toggling (Ctrl+/) and auto-indent after vectfn/if/els/lo.
  • Snippets: vheader, vectfn, vif, vlo, vlow, vmath, varr, vfile, vkv, vclock, vecho.

Report issues

Wrong colors, missing keywords, bad indent? Send the snippet + a screenshot to vectlangsupport@proton.me.
