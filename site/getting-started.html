Getting started in 5 minutes

1 · Install (2 min)

Windows x64, via Scoop:

> scoop bucket add vect https://github.com/MerixCipher/scoop-bucket
> scoop install vect/vectc

No Scoop? Grab the zip on the download page, unzip, and run vectc from that folder. Verify with vect --version.

2 · First program (2 min)

Save this as hello.vt next to mvga.vth (or any folder — includes resolve relative to your file):

vt.init
mvga.vth
(main)
branch
vectfn main
    echo "Hello, World!"
main()
> vect hello.vt
Hello, World!

3 · What just happened (1 min)

The four header lines boot the runtime and jump to main. vectfn main defines it, echo prints, main() calls it. Three ideas carry the whole language from here:

  • Compact assignment: x10 means x = 10.
  • Target math: (c.a+b) means c = a + b.
  • Indentation: blocks are 4 spaces, one statement per line.

Day 2 · read errors like a local

Break your hello on purpose — delete a quote, mistype echo, divide by zero. Each fault prints [Vect Runtime Error]: … at line N and exits 1. The error catalog lists every message with its cause and fix; after a week you'll read them faster than the docs.

Day 3 · build something real

Follow the Hangman tutorial end to end (~50 lines), then change the word, add a life, persist the best score. That loop — write, run, read the error, fix — is the whole Vect workflow.
