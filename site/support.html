Support

Which inbox?

AddressUse for
vectlangsupport@proton.meBugs, install trouble, how-to questions. Include reproducers (below).
vectlang@proton.meOfficial contact: press, partnerships, business, commercial licensing.

Support mail is triaged automatically; anything the bot can't answer is handed to a human. If a reply didn't help, just reply again saying so.

Bug report template

Copy, fill, send. Reports with reproducers get fixed first.

Vect version:  (vect --version)
Command run:   (e.g. vect program.vt)
Expected:      (what should happen)
Actual:        (full error output, pasted)
Program:       (attach the smallest .vt that breaks)

Response expectations

  • Crashes / wrong output with reproducer: first priority.
  • Install and usage questions: best effort, usually within days.
  • Feature requests: collected for roadmap planning, no promises per release.

Before you email: 60-second self-help

  1. Run vect --version — half of all reports are fixed by updating.
  2. Read the error line number, open that line. 80% end here.
  3. Search the error catalog for the message.
  4. Reduce to the smallest program that still breaks (delete half, re-run, repeat).
  5. Still broken? Send the small program + full output. You'll usually get back a fix, not questions.

Security

Found something that looks like a vulnerability (rather than a normal bug)? Write to the cybersecurity team with subject [security] — it skips the bot queue. Every release is VirusTotal-scanned before announcement regardless.

Commercial use

Running your own programs is covered by the free-use terms in TERMS.txt. Redistributing the compiler, embedding it, or building products on the toolchain needs a conversation first: vectlang@proton.me.
