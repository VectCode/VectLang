File formats

.vt source files

  • UTF-8 text, LF or CRLF line endings (both accepted).
  • 4 spaces per indent level (tabs count as 4).
  • One statement per line; blank lines ignored.
  • Header block first: vt.init, optional *.vth lines, (main), branch.
  • Max source size: 10 MB per file (2 MB per header).

.vth header libraries

  • Same syntax as .vt, but level-0 lines may only be comments, header lines, or vectfn definitions — executable top-level code is rejected.
  • Resolved relative to the file naming them; nest freely; each file loads once (repeats skipped, cycles safe).
  • Line numbers in errors carry the header filename.

.kv store files

Written by kvsave, read by kvopen. Text format, one record per line, length-prefixed so any bytes are safe:

T<klen>:<key><vlen>:<value>\n
TagTypeExample
SstringS4:name4:vect
IintI5:score2:99
FfloatF2:pi4:3.14

Hand-editable in a text editor. A malformed file halts with Corrupt store — delete it to start fresh. Missing file on kvopen starts empty (created on first kvsave).

.vt line grammar (informal)

Every non-blank line is exactly one of these, in matching order (first match wins):

#FormExample
1Header (vt.init, *.vth, (main), branch, vect)vt.init
2vectfn name.a, bvectfn add.a, b
3rtn exprrtn sum
4if cond / elsif x > 10
5loN / loNw condlo10w done == 0
6I/O & stores (echo echow in set fopen fwrite fclose kvopen kvset kvdel kvsave kvclose vga pout)echow sec, 200
7(target.rest)(c.a+b)
8name(...) — call or array allocarr(5)
9name"lit" string assignmsg"hi"
10nameDigits int assignx10
11nameFloat float assigny3.14

Anything else is Unknown statement. Note rule 6 beats rule 10: a line starting with a keyword is a statement even if it ends in digits (ind0 assigns because in requires a space or paren after it — same guarding applies to lo/vga/pout).

Name rules

  • Start with a letter or _, then letters/digits/_.
  • Trailing digits on a bare token are the value (count100), so digits inside names only survive when followed by non-digits.
  • Reserved in target expressions: sqrt bit get len char cmp cat clock chr fread kvget kvexists — don't name functions these.
  • Case-sensitive: Score and score are different variables.
