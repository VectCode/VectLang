Old versions, kept for archival purposes. Scoop always serves the latest release — these zips are the only way to get earlier ones.

0.2.1 — first public release

The foundation everything since is built on: the bytecode compiler + stack VM replacing the original tree-walk interpreter, real stdout, file primitives (fopen/fread/fwrite/fclose), real .vth includes, if/els branches, and the first Scoop + website distribution. If 0.2.3 ever misbehaves, this is the fallback that proves the lineage.
